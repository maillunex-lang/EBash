# Клиент EBash на Godot

Решения: движок Godot (D-092), сервер авторитетен, клиент только отображает ([architecture](../../../docs/gdd/architecture.md)). Правила карты и камеры — [maps](../../../docs/gdd/maps.md), интерфейса — [ui](../../../docs/gdd/ui.md). Читай нужный раздел через `rg -n '^## '`, а не целиком.

## Границы

- Клиент не считает достоверную экономику: цены, тики, деньги и выпуск приходят с сервера. Локальные расчёты — только предварительные оценки или демо в прототипе с пометкой.
- Язык — только GDScript (D-093), C# не используй. Версия — Godot 4.7.2 (D-094); не меняй её без решения владельца. Прототип пока проверен только на 4.6.3: после открытия в 4.7.2 перезапусти smoke и обнови README прототипов.
- Только синтаксис Godot 4: `await` (не `yield`), `CharacterBody3D` (не `KinematicBody`), `@export`/`@onready` (не `export`/`onready`), `signal.connect(callable)` (не `connect("sig", self, "m")`), `instantiate()` (не `instance()`), `Node3D` (не `Spatial`). Сомневаешься — сверяйся с документацией именно 4.x.
- Не добавляй плагины, ассеты из магазина, аналитику, рекламу и покупки без решения владельца.

## Технические правила

- Рендерер `gl_compatibility` для мобильных (в `project.godot`); не меняй без замеров на телефоне.
- 3D-модели и ортографическая камера с фиксированным направлением; управление — перетаскивание и масштаб пальцами.
- Строгая типизация обязательна: типы у переменных, параметров и возвращаемых значений (`var x: int`, `:=`, `-> void`), типизированные массивы `Array[Node3D]`. Отступы — как в существующем файле.
- Логику, которую проверяет smoke-тест, держи в публичных методах сцены без зависимости от ввода (пример: `select_cell`, `advance_tick` в `prototypes/godot/Main.gd`).
- Тексты интерфейса на русском; размер шрифта читаем на телефоне (не меньше ~18 px при 1280×720).
- Новый код меняй вместе со smoke-проверкой: `prototypes/godot/smoke.gd`.

## Проверка

`godot --headless --path prototypes/godot --script smoke.gd` должен печатать `SMOKE OK`. Сборка APK и проверка на телефоне — навык `ebash-android-build`. Headless не заменяет визуальный осмотр на устройстве: так и пиши в отчёте.
