# Прототипы

Источник истины — `prototypes/README.md` (состав, сценарий, команды сборки, текущее состояние). Не дублируй его.

- Оба прототипа должны показывать одинаковый сценарий: изменения сцены вноси в оба или явно помечай расхождение в README.
- Godot smoke: `godot --headless --path prototypes/godot --script smoke.gd`.
- Unity без активированной лицензии не компилируется: не утверждай, что код проверен.
- Экономические числа в прототипах условны и не являются решениями GDD.
- Ключи подписи, APK и служебные папки редакторов не коммить (см. `.gitignore`).
- Результаты проверки записывай в раздел «Текущая проверка» README прототипов.
