# Прототипы

Источник истины — `prototypes/README.md`. Выбран Godot (D-092): работа идёт в `prototypes/godot` по навыкам `ebash-godot` и `ebash-android-build`.

- Unity-прототип (`prototypes/unity`) сохранён для истории: не развивай и не удаляй без просьбы владельца.
- Экономические числа в прототипах условны и не являются решениями GDD.
- Ключи подписи, APK и служебные папки редакторов не коммить (см. `.gitignore`).
- Результаты проверок записывай в «Текущая проверка» README прототипов.
