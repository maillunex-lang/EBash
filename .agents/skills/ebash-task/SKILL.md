# Выполнение задачи

1. Открой `docs/tasks/<ID>.md`. Если ID не задан, выбери в `docs/tasks/INDEX.md` первую задачу со статусом «готова к проектированию» или «готова к реализации». Заблокированные не бери.
2. Проверь, что зависимости выполнены (статус «выполнена» в очереди). Если нет — остановись и сообщи.
3. Читай только ссылки из раздела «Читать». Решения из списка ищи точечно: `rg -n 'D-0NN' docs/decisions/001-foundation.md`.
4. Пиши результат в файлы из раздела «Объём». Новые правила помечай «Предложение» до выбора владельцем; варианты давай с рекомендацией.
5. Поставь статус «в работе», после готовности — «ожидает решения» (проектирование) или «выполнена» (после согласования). Статус меняй одинаково в файле задачи и в `INDEX.md`.
6. Заполни раздел «Результат»: изменённые файлы, проверка, открытые вопросы.
7. Запусти `python3 scripts/check_docs.py`.
