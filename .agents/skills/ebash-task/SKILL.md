# Выполнение задачи

1. При известном ID открой файл задачи. Если поручена тема без ID, выбери строку в `docs/READING.md`. Если нужна следующая работа по всему проекту, открой `docs/roadmap/stages.md` и возьми первый актуальный пакет.
2. Проверь, что зависимости выполнены (статус «выполнена» в очереди). Если нет — остановись и сообщи.
3. Читай только ссылки из раздела «Читать». Решения из списка ищи точечно: `grep -n 'D-0NN' docs/decisions/001-foundation.md`.
4. Пиши результат в файлы из раздела «Объём». Для новых правил применяй делегирование D-181 и записывай обоснованные решения через ebash-decision. Непроверенные предположения помечай как предложения.
5. Поставь статус «в работе», после готовности — «ожидает решения» (проектирование) или «выполнена» (после согласования). Статус меняй одинаково в файле задачи и в `INDEX.md`.
6. Заполни раздел «Результат»: изменённые файлы, проверка, открытые вопросы.
7. Запусти `python3 scripts/check_docs.py` и профильные проверки из `docs/READING.md`; `git diff --check`. **Запрещён GitHub** до отдельной команды; не пытайся исправлять грязный Git удалением файлов.
