# Выполнение задачи

1. Для E-101…E-108 открой раздел по ID в [очереди реализации](../../../docs/roadmap/implementation-backlog.md). Для DES открой один файл по ID в [реестре спецификаций](../../../docs/tasks/INDEX.md). Если поручена тема без ID, выбери строку в `docs/READING.md`. Если нужна следующая работа по всему проекту, открой `docs/roadmap/stages.md` и возьми первый актуальный пакет.
2. Для DES проверь зависимости из файла задачи. Для пакета E используй его критерий приёмки и ограничения интеграции.
3. Читай только ссылки из раздела «Читать». Решения из списка ищи точечно: `grep -n 'D-0NN' docs/decisions/001-foundation.md`.
4. Пиши результат в файлы из раздела «Объём». Для новых правил применяй делегирование D-181 и записывай обоснованные решения через ebash-decision. Непроверенные предположения помечай как предложения.
5. Для DES поставь статус «в работе», после готовности — «ожидает решения» (проектирование) или «выполнена» (после согласования). Статус меняй одинаково в файле задачи и в `INDEX.md`.
6. Для DES заполни раздел «Результат». Для E запиши результат в профильный протокол: изменённые файлы, проверка, открытые вопросы.
7. Запусти `python3 scripts/check_docs.py` и профильные проверки из `docs/READING.md`; `git diff --check`. **Запрещён GitHub** до отдельной команды; не пытайся исправлять грязный Git удалением файлов.
