# Работа с проектом

- Сначала прочитай docs/INDEX.md; затем только документы, необходимые для текущей задачи.
- Утверждённые решения находятся в docs/decisions/001-foundation.md. Не выдавай предложения и открытые вопросы за утверждённые требования.
- Каждый факт подробно описывается в одном профильном документе; в остальных местах используй ссылки.
- Документы и обсуждение ведём на русском. Идентификаторы задач стабильны.
- Не выбирай самостоятельно название, сюжет, стек, монетизацию или масштаб первой версии: они требуют совместного выбора с владельцем.
- Перед реализацией задачи проверь её зависимости и критерии приёмки. Если их нет, задача ещё не готова к реализации.
- Обновляй индекс при добавлении документов. Не читай все файлы рекурсивно без необходимости.
