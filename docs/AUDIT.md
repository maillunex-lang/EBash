## Пределы проверки

`scripts/check_docs.py` проверяет только Markdown: inline-ссылки и якоря, существование и уникальность ID решений, достижимость документов от README, структуру задач и отсутствие циклов. Код прототипов, экономический баланс и reference-style ссылки не проверяются.

## Когда пересмотреть

- Реестр решений больше ~150 строк — разбить на разделы по темам.
- Появление каталогов рецептов и районов — у каждого свой индекс.
- Появление задач реализации — добавить их префикс в проверку.
