# Передача EBash

- **Есть конкретная задача.** Открой её файл из [очереди DES](tasks/INDEX.md) или выбери строку в [маршрутах чтения](READING.md). Этого достаточно для входа в работу.
- **Передан весь проект.** Прочитай [текущее состояние](STATUS.md) и выбери первый актуальный пакет в [дорожной карте](roadmap/stages.md).
- **Рабочие ограничения.** Начни с [AGENTS.md](../AGENTS.md). Рабочая копия на Lunex, публикация на GitHub по отдельной команде владельца.
- **Где проверить.** В [маршрутах](READING.md) указаны исходники и проверки по теме. Решения ищи по ID. [Полная карта документов](INDEX.md) нужна для поиска за пределами выбранной темы.

После работы обнови документ, который отвечает за изменившийся факт. Готовность отражай в статусе, порядок разработки — в дорожной карте, приёмку отдельной задачи — в самой задаче.
