# Текущее состояние EBash

**18.11.2026.** На Lunex работает прототип Go/PostgreSQL и Godot 4.7.2. Демомир пекарни проводит две партии через управление тиками из Godot. Автоматический прогон проходит, ручная графическая проверка и проверка на Android впереди. [Запуск и проверки](../server/README.md)

| Область | Что уже есть |
| --- | --- |
| Производство | Семь тестовых цепочек, повторные партии и закупка на одну партию вперёд |
| Рынок | Выбор цены и срока поставки, конкуренция за один лот, пополнение запасов |
| Нагрузочная проверка | До 64 покупателей на один лот, четыре цикла продаж и пополнения в тестовой базе |
| Каталоги | У всех 105 черновых операций есть версионированные справки. Исполняемые производственные профили и каталог городов остаются в [DES-004](tasks/DES-004.md) |
| Проектирование | Формальные статусы спецификаций в [очереди DES](tasks/INDEX.md) |

Следующий порядок работ хранится в [дорожной карте](roadmap/stages.md). Числа пилота относятся к тестовой экономике. Публикация на GitHub регулируется [AGENTS.md](../AGENTS.md).
