# EBash: действующие инварианты для исполнителя

Это **короткая карта уже принятых решений**, а не замена профильных GDD и не новый набор правил. При задаче с известным ID сначала читай [её описание](../tasks/INDEX.md); подробности искать по D-ID в [реестре](../decisions/001-foundation.md) и в соответствующем разделе.

| Подсистема | Только актуальная основа | Подробности |
| --- | --- | --- |
| Платформа и мир | Android, ландшафтная ориентация, Godot 4.7.2/GDScript; Башкортостан, игровой старт в 2027, общий постоянный рынок | D-001–D-009, D-039, D-049, D-092–D-094; [архитектура](architecture.md) |
| Время | **24 реальных часа = игровой месяц** (28–31 день), один игровой день соответствует серверному тику | D-004/D-005; [время](time.md), [DES-001](../tasks/DES-001.md) |
| Отложенные товары | Готовая продукция тика T продаётся с T+1, промежуточная может идти на следующую ещё не исполненную линию в T; поступившая извне поставка доступна производству только T+1 | D-095/D-096/D-125/D-133; [производство](production.md) |
| Дефицит и партии | Целые рецептурные партии с минимумом рецепта, без двойного расхода; первично максимум числа выполнимых партий, затем минимальная нормированная ошибка квот; точный поиск до 8 конкурирующих линий, для больших задач временной бюджет поиска 100 мс и безопасный fallback | D-097–D-123, D-128–D-135; [DES-002](../tasks/DES-002.md) |
| Качество | Шкала 1–100; сырьё/технология/оборудование/персонал/условия с весами **30/25/20/15/10**; итоговое округление 0,5 вверх; совместимость партий обязательна | D-105–D-107, D-131/D-132/D-136/D-137; [качество](quality.md) |
| Рецепты | Контракт с ID, версией, входами/выходами, минимальной партией, оборудованием, энергией, трудом и качеством; отсутствует обязательный параметр → **не запускать** | D-138/D-139/D-140; [каталог](../catalogs/INDEX.md) |
| Сетка предприятия | Девять ячеек **3×3**, связи могут соединять любые ячейки; закупочная ячейка обслуживает только один товар | D-019–D-022; [сетка](facility-grid.md) |
| Рынок | Спрос ограничен бюджетом, потребностями, запасом и зоной обслуживания. Сегменты отличаются чувствительностью к цене/качеству; единый снимок тика, прослеживаемость товаров и денег | D-141–D-150/D-153; [рынок](market.md) |
| Рабочий баланс DES-003 | **Временные**, не проверенные на MMO цифры v1: цена 65–150% ориентира; допустимая безопасная уценка до 40%; базовая квота города 20 ед. на компанию/товар/игровой месяц, ещё до 20 ед. с наценкой 35%. Делегировано **только DES-003** | D-149–D-152; [цены](pricing-integrity.md), [городское снабжение](city-supply.md) |
| Объём первой версии | **100+ полноценных рецептов**, основные города Башкортостана, несколько отраслей. Сейчас 108 **неисполняемых черновиков**, а не готовых рецептов | D-040; [DES-004](../tasks/DES-004.md) |

**Граница готовности:** DES-001/002/003 завершены как **спецификации**. Пилотный сервер Go/PostgreSQL и интеграционные тесты существуют; экспериментальный DES-002/004 планировщик **не включён в штатный тик**. Полная MMO-экономика и Android-приёмка не завершены. Новые концептуальные решения требуют владельца. Любой ИИ работает только на VPS Lunex, **GitHub не трогает до отдельной команды**. Начало передачи: [HANDOFF](../HANDOFF.md).
