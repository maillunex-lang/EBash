# Администрирование и публикация баланса

## Утверждено

Отдельный веб-кабинет администратора, доступный через браузер. На старте один общий уровень административных полномочий; разделение на роли поддержки, модерации и контента не выбрано. Общий уровень не означает общую учётную запись или публичный доступ; механизм входа ещё проектируется.

Изменение рецептов и баланса проходит путь: черновик → проверка → публикация новой версии на границе серверного тика. Сохраняется история изменений. Конкретный проверяющий, правила проверки и влияние версии на действующие партии, производства и договоры пока открыты.

Система собирает признаки подозрительных связей и сделок; решение принимает модератор. Автоматический бан и временная автоматическая задержка операции по одному подозрению не выбраны. Обычная серверная проверка допустимости цены, средств и ресурсов продолжает действовать по [правилам рынка](pricing-integrity.md).

## Требует проектирования

- Вход в кабинет и индивидуальные учётные записи администраторов.
- Перечень функций, ограничений и журнал действий с причиной изменений.
- Наблюдение тиков, поиск компаний и сделок, обращения игроков.
- Доказательства для модерации, санкции, обжалование и сроки обработки.
- Хранение версий, проверка совместимости и откат без повторного расчёта экономики.
- Обработка неуспешной публикации на границе тика.

Выбор одного уровня доступа не разрешает произвольное изменение денег игроков и не задаёт перечень санкций: эти полномочия требуется описать отдельно.

Вход администратора по паролю. Обязательный второй фактор не выбран. Это решение не означает общую учётную запись всех сотрудников.
