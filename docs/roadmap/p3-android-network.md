# Сетевой Android-клиент

Текущий маршрут — [главное меню, республика и город](../gdd/maps.md). [Параметры подключения](p3-public-path.md) · [сборка](../../prototypes/README.md). На телефоне предстоит проверить ввод личных параметров доступа, повторный вход, потерю связи, поиск и первую продажу.

## Реализовано

- `Launcher.tscn` открывает серверную пекарню или прежний визуальный прототип карты.
- Пекарня предлагает ввод HTTPS URL, ID мира и личного токена, если конфигурация не передана через окружение. Поле токена скрыто; токен не сохраняется на диске. HTTP в Android-форме не разрешён; локальный `127.0.0.1` сохранён для headless-тестов VPS.
- Клиент продолжает обращаться к существующим `/v1/worlds/{world}/...` API; склад, сделки, поставки и деньги рассчитываются сервером.
- Android экспорт содержит `android.permission.INTERNET`; подпись v2/v3 проверена. APK: `/home/gamedev/ebash-build/ebash-p3-network-20261118.apk`.
- Godot `demo-smoke` (две партии) и offline-проверки успешно пройдены.

## Открытые вопросы на момент первой сборки

1. **Изолированная тестовая БД и отдельный API-процесс** для Android; в данном пакете не запущены как постоянно работающие службы. Не использовать производственные БД и токены других проектов.
2. **HTTPS reverse proxy** с валидным сертификатом и отдельным маршрутом EBash. Наличие nginx на VPS не означает готовый безопасный публичный endpoint. Не менять действующую конфигурацию nginx и чужие виртуальные хосты без отдельной проверки.
3. Выдать пользователю индивидуальные параметры тестового мира защищённым способом. Не встраивать токен в APK или Git.
4. На реальном Android подтвердить TLS, авторизацию, отображение склада/рынка, заказы, поставки и продажу; ручная приёмка согласована на P4.
5. В экспорте Godot пока отсутствует иконка приложения. APK является debug-сборкой, не релизом.

## Запуск проверок

`PG_BIN_DIR=... GODOT_BIN=... EBASH_PILOT_MODE=demo-smoke bash server/check_godot_pilot.sh` из корня (или из server без префикса). `python3 scripts/check_all.py`.

## Игровой экран пекарни E-104

На экране видны цель на две партии, кошелёк и склад, варианты поставки, ожидаемый тик прибытия и действие продажи. Сквозной `profile-demo-smoke` проверяет цель от 0 до 2 и проводит две продажи с разными мельницами.

Новый debug APK `0.2.0-test` собран на Lunex в `/home/gamedev/ebash-build/ebash-e104-bakery-0.2.0-test.apk`. ABI arm64-v8a, разрешение INTERNET и подписи v2/v3 проверены. Публичная раздача APK не обновлялась. Для прохода на телефоне нужен отдельный HTTPS-маршрут к миру с включёнными профилями E-104 и личный токен. Ручная проверка на устройстве ещё не проведена.
