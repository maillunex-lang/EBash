### Первоначальные условия

На VPS обнаружен действующий HTTPS-виртуальный хост `rikagro.ru` для других приложений. Использовать корпоративный домен для EBash без явного согласования нельзя. Отдельного подтверждённого домена/поддомена и TLS-сертификата для EBash пока нет. Публичный HTTPS endpoint **не настроен**.

После согласования отдельного доменного имени: настроить DNS A/AAAA на VPS, выпустить доверенный сертификат, создать отдельный nginx server block для EBash с `proxy_pass http://127.0.0.1:18749`, ограничить размер запросов и частоту обращений, протестировать HTTPS и авторизацию с внешней сети. До этого порт 18749 не открывать публично и не использовать HTTP для Android.

## Операционные проверки

`systemctl status ebash-p3-db ebash-p3-api` и `ss -ltn | grep 18749`. Локальный токен получать только с правами `gamedev`, не выводить в чат или логи. Не выполнять `seed` повторно на существующем мире. Для тестовой базы пока нет автоматического offsite-бэкапа; это не производственный контур.
