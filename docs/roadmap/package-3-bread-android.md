## Не закрыто

1. **DES-004**: реальные нормы энергопотребления, персонала, влажности и выхода, минимальных партий и критерии качества требуют подтверждённых измерений. Черновые рецепты `draft_not_executable` **не разблокированы**; игровые пилотные допущения не подменяют подтверждение каталога.
2. APK пока запускает `Main.tscn`, а интерактивный `Pilot.tscn` требует переменных окружения и локального API. Поэтому APK является технической сборкой, **не автономной играбельной версией пекарни на телефоне**. Для P3 нужен безопасный способ конфигурации сетевого клиента на Android и тестовый HTTPS-сервер без публичных тестовых секретов.
3. Ручная проверка на Android отложена до P4 по решению владельца. Не подтверждены визуальная безопасная зона на конкретном устройстве, удобство интерфейса и сетевые прерывания.
4. Экспорт завершился успешно, но Godot сообщает об отсутствующей иконке проекта. Требуется отдельный ассет перед релизной сборкой.

**Статус:** техническая часть P3 выполнена, выпуск игрового Android-клиента и утверждение профиля остаются открытыми. GitHub не обновлялся.
