# Дорожная карта EBash

**Версия 18.11.2026.** [Статус](../STATUS.md) содержит факты, этот файл только последовательность и критерии перехода. Подробный исполнимый [backlog](implementation-backlog.md). Исторические пакеты сохранены ссылками, а не копируются сюда.

| Этап | Статус | Критерий перехода |
| --- | --- | --- |
| P0–P1: GDD и правила | Основные DES-спецификации завершены; DES-004 открыт | Решения и инварианты согласованы; новые концептуальные изменения отдельно утверждать |
| P2: технический пилот | Проверенные отдельные Go/PostgreSQL и Godot сценарии | Детерминированные тики, идемпотентность, поставки и восстановление |
| P3.2a: производство | **В работе**, экспериментальный планировщик отдельно от штатного сервера | Все критические инварианты DES-002, ресурсные компоненты, циклы, 9+ линий, атомарность, тесты на ошибках |
| P3.2b: интеграция экономики | **Частично реализована в изолированном состоянии, без торгового HTTP API** | Единые склады, резервы, доставка T+1, продажа T+1, журналы, два аккаунта и HTTP/PostgreSQL тесты |
| P3.3: Android-игровой срез | Пилот есть, новая экономика не подключена | Полный путь игрока на настоящем Android, безопасная зона, ландшафт, сеть и ошибки UX |
| P3b: отрасли и города | Каталог 105 черновиков, **не готов** | 100+ проверенных исполняемых рецептов, реальные городские справочники, отраслевые и 3×3 проверки |
| P4: закрытая альфа | **Не начата** | Многодневные тесты, эксплуатация, злоупотребления, ускоренная [лаборатория баланса](alpha-balance-lab.md) |
| P5: релиз | **Не начат** | Стабильная Android-сборка, мониторинг, поддержка, проверка безопасности |

**Порядок:** P3.2a → P3.2b → P3.3 → расширение P3b → P4 → P5. Разработка отдельных рецептов и UI может идти параллельно без преждевременного подключения черновиков. Не считать тестовый APK релизом.
