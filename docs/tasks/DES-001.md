# DES-001 — Спецификация серверного тика

Тип: проектирование.
Статус: готова к проектированию.

## Цель

Подготовить порядок фаз, границу приёма распоряжений, правила доступности результатов и восстановления после простоя.

## Зависимости

Нет. Можно начать подготовку предложения.

## Объём

Выход: docs/gdd/time.md. Новые правила остаются предложениями до выбора владельцем.

## Приёмка

Есть последовательность одного дня, границы месяца, пример закупки → доставки → выпуска → продажи; разобраны повторный расчёт и нехватка входов. Все ещё не выбранные правила обозначены предложениями.

## Проверка

Числовые сценарии и ручная проверка приёмки; `python3 scripts/check_docs.py` из корня репозитория. Завершение зависимостей означает согласованную спецификацию, а не просто написанный черновик.

## Результат

Пока не выполнено. Исполнитель фиксирует файлы, сценарии и оставшиеся вопросы.
