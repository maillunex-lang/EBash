# DES-004 — Каталоги городов и производственных цепочек

Тип: проектирование.
Статус: в работе.

## Цель

Предложить перечень основных городов и связанных отраслей, схему данных товаров и рецептов, затем состав каталога 100+ рецептов с источниками.

## Объём

Выход — записи и источники выбранной цепочки в [каталоге](../catalogs/INDEX.md). Новые правила остаются предложениями до выбора владельцем.

## Приёмка

У каждого рецепта стабильный ID, входы/выходы, единицы и оборудование; цепочки достижимы от сырья, помещаются по стадиям в 3×3; допущения отделены от фактов. Для проверочного набора городов указан статус по D-177, для новых городов приведены источники.

## Проверка

Числовые сценарии и ручная проверка приёмки; `python3 scripts/check_docs.py` из корня репозитория. Завершение зависимостей означает согласованную спецификацию, а не просто написанный черновик.

## Результат

Граф и справочные источники доступны в [индексе каталога](../catalogs/INDEX.md). Проверены версии, связность графа и блокировка черновых профилей. Прототип Godot использует отдельные игровые параметры.

- Начать с хлебной цепочки. Подтвердить единицы и замеры по [профилю хлеба](../catalogs/wheat-bread.md), потери и фактические выходы, оборудование, энергию, людей и критерии качества.
- Затем проводить остальные цепочки пакетами по критериям каталога. Отдельно проверить список и источники для городов.
- Для одной цепочки запустить `python3 scripts/check_des004_catalog.py --chain ID_ОПЕРАЦИИ`, для обзора семейства использовать вывод `--batch`. Весь каталог нужен только для работ по схеме или общему аудиту.

Подробные результаты итераций находятся в [истории](DES-004-history.md). Очерёдность игрового демо находится в [дорожной карте](../roadmap/stages.md).
