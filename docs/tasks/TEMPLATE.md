# TASK-NNN — Краткое действие

Статус: черновик / готова / в работе / выполнена.

## Цель

Какой результат нужен и зачем.

## Читать

Точные ссылки на необходимые разделы; не весь GDD.

## Зависимости

ID решений и задач. Перечислить открытые вопросы, блокирующие реализацию.

## Объём

Конкретные изменения и границы задачи.

## Приёмка

Наблюдаемые условия, по которым можно проверить результат.

## Проверка

Подходящий сценарий или команда; для расчётов — входные данные и ожидаемый результат.

## Результат

Заполняется исполнителем: изменённые файлы, проверка, оставшиеся ограничения.
