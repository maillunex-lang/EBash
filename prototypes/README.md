# Сравнительные прототипы

**Итог: владелец выбрал Godot (D-092).** Дальнейшая работа — в `godot/`; `unity/` сохранён для истории и не развивается.

GDD временно приостановлен по просьбе владельца. Цель — получить два APK с сопоставимыми сценами, а не реализовать полную игру.

## Состав

- Godot: `godot/project.godot`, версия 4.6.3.
- Unity Personal: `unity/`, проект под 2022.3.62f1; требуется редактор с Android Build Support и активацией Personal.

Одинаковый базовый сценарий: условный город из 49 зданий, фиксированная ортографическая камера, перемещение/масштаб, обзор городов, режим компании, сетка 3×3, выбор ячейки, демонстрационная связь, смена продукта, локальный тик и переключение 30/60 FPS.

Графика состоит из простых процедурных моделей. Обзор республики пока список городов; все города используют одну сцену. Это не финальная карта Башкортостана. Экономические числа условны; сервера, покупок, аккаунтов и сохранения прогресса нет. Методы создания UI отличаются: Godot Control и Unity IMGUI, поэтому результаты пока не являются строгим сравнением производительности движков.

## Сборка

Godot: установить Android export templates 4.6.3, JDK и Android SDK, настроить пути в Editor Settings и debug keystore. Из корня: `godot --headless --path prototypes/godot --export-debug Android /путь/ebash-godot.apk`.

Unity: активировать Personal в Unity Hub, установить редактор с Android Build Support (SDK/NDK/OpenJDK). Открыть `prototypes/unity` или выполнить `Unity -batchmode -quit -projectPath /путь/prototypes/unity -executeMethod BuildPrototype.BuildAndroid -logFile /путь/unity-build.log`. Для выходного APK можно задать переменную `EBASH_APK_PATH`. Ключи подписи не хранить в репозитории.

## Проверка на телефоне

Использовать одно устройство и одинаковую частоту кадров. Проверить запуск, читаемость текста, перетаскивание, масштаб, переходы компании и города, выбор ячеек. Замерить FPS, нагрев и расход памяти после одинакового времени работы. Headless-запуск не заменяет проверку Android и визуальный осмотр.

Unity-сборка требует доступного лицензированного редактора; наличие исходников не означает, что APK собран или код проверен компилятором.
